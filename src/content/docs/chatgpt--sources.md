## Gaps (no public image found)

- **Limit message (variant A, a1-limit-wall).** Wording and layout are a reconstruction: assistant-style text "You've hit the Free plan limit for image uploads. Upgrade to Plus to keep going, or try again after 3:40 pm." with a black "Get Plus" pill.
- **+ menu (a0 / b1).** Layout is a reconstruction: Camera / Photos / Files tiles, then Create image, Thinking, Deep research, Web search rows. The exact current set and order were not verified.
- **Send button with text typed.** App Store shots only show the empty composer (blue voice button). The prototype turns the same blue button into an up-arrow send button.
- **Settings › Usage page.** Engadget says one exists; no screenshot found, so it is not re-created.
